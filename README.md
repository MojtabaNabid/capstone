# Restaurant Website | React Capstone Project

A restaurant website built with **React.js** as a frontend capstone project. The application brings together restaurant information, page navigation, and reservation-related user interactions in a component-based web interface.

## Project Overview

This project demonstrates practical frontend development with React, including reusable UI components, client-side routing, and user-facing forms. It was created as a capstone project to apply core React concepts in a restaurant website scenario.

## Features

- **Restaurant website interface:** Pages and sections for presenting restaurant content.
- **Table reservation flow:** A user-facing interface for entering reservation information.
- **Form interactions:** Input handling and validation for interactive forms.
- **Client-side navigation:** Navigation between views using React Router.
- **Component-based structure:** Reusable React components to organize the user interface.

> **Note:** This is a frontend-focused project. The repository does not establish that reservations are stored in a production database, that payments are processed, or that user accounts are backed by an authentication service.

## Technologies

- React 18
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router DOM 6
- Create React App (`react-scripts`)
- React Testing Library and Jest DOM (included in project dependencies)

## Getting Started

### Prerequisites

Install **Node.js** and **npm** on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/MojtabaNabid/capstone.git
   ```

2. Open the project directory:

   ```bash
   cd capstone
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts
